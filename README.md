## ④アプリのログイン用IDまたはPassword（ある場合）


## ⑤工夫した点・こだわった点
- 100問以上の問題を用意。スプレッドシートに問題を追加すると、アプリにも反映される仕様。
- 問題の難易度に応じて、1問ごとに制限時間を設定。
- 問題はランダムに出題され、間違えた回数が多い問題ほど出題頻度が高くなるように工夫。
- 連続正解数に応じて、ご褒美の画像が飛び出す演出を追加。

## ⑥難しかった点・次回トライしたいこと（又は機能）
- 問題ランダムはうまくいったが、間違えた回数が多い問題出題頻度の計算式が非常に難易度が高かった
